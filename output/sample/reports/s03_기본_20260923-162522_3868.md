# 달빛 우체국 E01 한국어 강제 자막 분석

> 질문: 달빛 우체국 E01 한국어 강제 자막은 어느 대사·화면 글자에 붙었고, 같은 회차 한국어 SDH와 견주면 무엇이 빠지거나 더해졌는가? 예시플릭스 강제 자막 규정에 비춰 보라.

본 보고서는 달빛 우체국 E01의 한국어 강제 자막과 한국어 SDH 트랙을 비교하여 어떤 대사와 화면 글자가 강제 자막에 포함되었는지, 그리고 두 자막 간의 차이점을 분석한다. 질문은 강제 자막에 포함된 대사와 화면 글자, 그리고 SDH와의 비교를 통해 어떤 내용이 빠지거나 더해졌는지를 다룬다.

## 달빛 우체국 E01 한국어 강제 자막

달빛 우체국 E01의 한국어 강제 자막과 SDH 트랙을 비교한 결과, 강제 자막에는 특정 대사와 화면 글자가 포함되지 않았고, SDH에는 추가적인 설명이 포함되어 있었다. 예를 들어, 큐 2(00:02:03)에서 강제 자막은 "어머니, 올겨울엔 / 꼭 내려갈게요"라고 옮겼으나, SDH에서는 이 대사 앞에 "[편지]"라는 설명이 추가되었다(«달빛 우체국 E01» 한국어 강제 자막 큐 2, «달빛 우체국 E01» 한국어 SDH 큐 26). 또한, 큐 3(00:04:18)에서는 강제 자막이 "실례합니다 / 우체국이 여기인가요?"라고 표현했지만, SDH에서는 "[사토, 일본어로]"라는 설명이 추가되었다(«달빛 우체국 E01» 한국어 강제 자막 큐 3, «달빛 우체국 E01» 한국어 SDH 큐 50). 이와 같은 방식으로, 큐 4(00:04:22)와 큐 5(00:04:28)에서도 강제 자막은 대사만 포함하고, SDH는 각각 "[사토, 일본어로]"라는 설명을 추가하였다(«달빛 우체국 E01» 한국어 강제 자막 큐 4, «달빛 우체국 E01» 한국어 SDH 큐 52; «달빛 우체국 E01» 한국어 강제 자막 큐 5, «달빛 우체국 E01» 한국어 SDH 큐 55). 이 외에도, 큐 6(00:04:32)에서는 강제 자막이 "1974년 여름, / 달빛 우체국 앞에서"라고 표현했으나, SDH에서는 "[엽서]"라는 설명이 추가되었다(«달빛 우체국 E01» 한국어 강제 자막 큐 6, «달빛 우체국 E01» 한국어 SDH 큐 57). 이처럼 강제 자막은 줄거리에 필요한 화면 속 글자를 포함하지 않거나, SDH에 비해 대사에 대한 설명이 부족한 경우가 많았다. 강제 자막에는 큐 1(00:00:35)에서 문구가 포함되어 있지 않았고, SDH에는 이 문구가 포함되어 있었다. 마지막으로, 큐 172(00:12:54)에서는 SDH에 "[사토, 일본어로]"라는 설명이 추가되었으나, 강제 자막에는 이 문구가 포함되어 있지 않았다(«달빛 우체국 E01» 한국어 SDH 큐 172, «달빛 우체국 E01» 한국어 강제 자막 큐 10). 이러한 차이점들은 강제 자막 규정에 따라 줄거리에 필요한 화면 속 글자가 누락된 경우로 볼 수 있다(«예시플릭스 강제 자막 규정» F-1.3).

## 맺음말
