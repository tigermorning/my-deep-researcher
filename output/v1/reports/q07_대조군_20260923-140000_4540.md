# 라스트 하우스의 번역 비교 분석

> 질문: 라스트 하우스의 한국어 번역·일본어 번역·중국어 간체는 영어 자막(원문 기준)의 같은 장면을 어떻게 줄였고, 각 언어 스타일 가이드의 어디에 근거하는가?

라스트 하우스의 한국어, 일본어, 중국어 간체 번역은 원문 영어 자막과 비교하여 각 언어의 스타일 가이드에 따라 어떻게 줄였는지를 살펴보았다. 각 언어의 번역은 주어진 장면의 의미를 전달하면서도 자막의 길이와 형식을 준수해야 한다.

## 한국어 번역

한국어 번역에서는 원문 자막의 길이를 고려하여 줄임말과 간결한 표현을 사용하였다. 예를 들어, "이 행성을 지구라고 부르다니 / 얼마나 부적절한가"는 "이 행성을 지구라고 부르다니 / 얼마나 부적절한가"로 그대로 유지되었지만, 다른 장면에서는 "비가 내리던 날"이 "비가 내리던 날"로 간단히 표현되었다. 이는 «넷플릭스 한국어 스타일 가이드 I. 번역 자막»의 I.11. Line Treatment에 따라 최대 두 줄로 제한되며, 텍스트는 일반적으로 한 줄로 유지되어야 한다는 규정을 따랐다.

## 일본어 번역

일본어 번역에서도 비슷한 방식으로 줄임말과 간결한 표현이 사용되었다. "이 행성을 지구라고 부르다니 / 얼마나 부적절한가"는 "この星を地球と呼ぶのは / おかしい"로 번역되었으며, "비가 내리던 날"은 "あの雨が来た日の記憶を / 皆 忘れない"로 표현되었다. 이는 «넷플릭스 일본어 스타일 가이드»의 I.11. Line Treatment에 따라 최대 두 줄로 제한되며, 텍스트는 일반적으로 한 줄로 유지되어야 한다는 규정을 준수한 결과이다.

## 중국어 간체 번역

중국어 간체 번역에서도 원문 자막의 의미를 유지하면서 간결하게 표현하였다. "이 행성을 지구라고 부르다니 / 얼마나 부적절한가"는 "称这颗星球为“地球”实在不妥"로 번역되었고, "비가 내리던 날"은 "所有人都记得 / 大雨降临那天 自己身在何处"로 표현되었다. 이는 «넷플릭스 중국어 간체 스타일 가이드»의 II.10. Line Treatment에 따라 최대 두 줄로 제한되며, 텍스트는 일반적으로 한 줄로 유지되어야 한다는 규정을 따랐다.

## 결론

라스트 하우스의 한국어, 일본어, 중국어 간체 번역은 각 언어의 스타일 가이드에 따라 자막의 길이와 형식을 준수하며 원문 자막의 의미를 효과적으로 전달하고 있다. 각 언어의 번역은 최대 두 줄로 제한되며, 텍스트는 일반적으로 한 줄로 유지되는 원칙을 따르고 있다. 이러한 접근은 자막의 가독성을 높이고, 시청자가 내용을 쉽게 이해할 수 있도록 돕는다.
