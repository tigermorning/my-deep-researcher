# 넷플릭스 한국 드라마의 한국어 강제 자막과 SDH 비교

> 질문: 넷플릭스 한국 드라마의 한국어 강제 자막(아파트 E09, 오싹한 연애 E09)은 어떤 대사·화면 글자에 붙었고, 같은 회차 한국어 SDH와 견주면 무엇이 빠지거나 더해졌는가? 넷플릭스 강제 자막 규정·한국어 가이드 I절과 맞는가?

본 보고서는 넷플릭스의 한국 드라마인 아파트 E09와 오싹한 연애 E09의 한국어 강제 자막과 SDH 간의 차이를 분석한다. 질문은 강제 자막이 어떤 대사와 화면 글자에 붙었는지, 그리고 SDH와 비교했을 때 어떤 내용이 빠지거나 더해졌는지를 다룬다. 이를 통해 넷플릭스의 자막 규정과 한국어 가이드 I절과의 일치 여부를 검토한다.

## 아파트 E09 강제 자막과 SDH 비교

아파트 E09의 강제 자막과 SDH를 비교한 결과, 두 트랙 간에 여러 대사와 화면 글자의 차이가 발견되었다. 예를 들어, 강제 자막에서는 "우리 언니"라는 대사가 포함되어 있으나, SDH에서는 이 대사가 누락되었다(«아파트 E09 한국어 강제 자막» 큐 2, «아파트 E09 한국어 SDH» 큐 115). 또한, 강제 자막에는 "샅샅이 뒤졌는데"라는 대사가 포함되어 있으나, SDH에서는 이 대사가 빠져 있다(«아파트 E09 한국어 강제 자막» 큐 3, «아파트 E09 한국어 SDH» 큐 120). 이와 유사하게, "서류가 아니라"라는 대사도 강제 자막에는 포함되지만 SDH에서는 누락되었다(«아파트 E09 한국어 강제 자막» 큐 4, «아파트 E09 한국어 SDH» 큐 123). 강제 자막에는 "장부 어디 있습니까?"와 "장부 나 주십쇼"라는 대사도 포함되어 있으나, SDH에서는 이 두 대사 모두 누락되었다(«아파트 E09 한국어 강제 자막» 큐 5, 6, «아파트 E09 한국어 SDH» 큐 150, 154). 또한, "거래를 하든 뭘 하든 / 할 수 있으니까"와 "언니 목숨까지 노릴 정도라면"이라는 대사도 강제 자막에는 포함되지만 SDH에서는 빠져 있다(«아파트 E09 한국어 강제 자막» 큐 7, 8, «아파트 E09 한국어 SDH» 큐 158, 166). 마지막으로, "해독 시작"이라는 대사도 강제 자막에는 포함되지만 SDH에서는 누락되었다(«아파트 E09 한국어 강제 자막» 큐 2, «아파트 E09 한국어 SDH» 큐 860). 이러한 차이는 넷플릭스의 한국어 스타일 가이드 I절의 규정에 어긋나는 부분이 있다. 특히, I.20 조항에 따르면 모든 플롯 관련 대사는 자막으로 포함되어야 하며, 강제 자막에서 누락된 대사들은 플롯에 중요한 요소로 보인다. 따라서 강제 자막과 SDH 간의 차이는 규정에 맞지 않는 부분이 존재함을 시사한다.

## 오싹한 연애 E09 강제 자막과 SDH 비교

오싹한 연애 E09의 강제 자막과 SDH를 비교한 결과, 두 트랙 간에 몇 가지 중요한 차이점이 발견되었다. 첫째, 강제 자막에서는 화면 글자 "싱가포르 / 비즈니스 네트워킹 초청장"이 포함되었고, SDH에서는 대사 "해외 출장 다녀오겠습니다"가 포함되었다(«오싹한 연애 E09 한국어 SDH» 큐 426). 이는 강제 자막이 화면에 나타나는 텍스트를 우선시한 반면, SDH는 대사를 중심으로 구성되었음을 보여준다. 둘째, 강제 자막에서는 "네"라는 대사가 포함되지 않았지만, SDH에서는 여러 번 "네"라는 대사가 등장하였다(«오싹한 연애 E09 한국어 SDH» 큐 327, 큐 328, 큐 333). 이는 강제 자막이 특정 대사를 생략한 반면, SDH는 대사의 흐름을 유지하기 위해 이를 포함한 것으로 보인다. 셋째, 강제 자막에서는 "[한숨] 그래요?"와 같은 대사가 포함되지 않았고, SDH에서는 이 대사가 포함되었다(«오싹한 연애 E09 한국어 SDH» 큐 329). 이러한 차이는 강제 자막이 특정 상황에서의 대사를 생략하는 경향이 있음을 나타낸다. 넷플릭스 한국어 스타일 가이드에 따르면, 강제 자막은 플롯에 중요한 경우에만 화면 텍스트를 포함해야 하며, 중복되는 내용은 삭제해야 한다(«넷플릭스 한국어 스타일 가이드 I. 번역 자막»). 따라서 강제 자막의 구성은 가이드라인에 부합하는 것으로 보인다. 그러나 SDH에서의 대사 포함은 플롯 전개에 더 많은 정보를 제공하는 것으로, 두 트랙 간의 차별성을 보여준다. 이러한 분석을 통해 강제 자막과 SDH의 차이를 명확히 이해할 수 있었다.

## 맺음말

아파트 E09의 강제 자막과 SDH 간에는 여러 대사와 화면 글자의 차이가 발견되었다. 강제 자막에는 '우리 언니', '샅샅이 뒤졌는데', '서류가 아니라', '장부 어디 있습니까?', '장부 나 주십쇼', '거래를 하든 뭘 하든 / 할 수 있으니까', '언니 목숨까지 노릴 정도라면', '해독 시작' 등의 대사가 포함되었으나, SDH에서는 이들 대사가 누락되었다(«아파트 E09 한국어 강제 자막» 큐 2, 3, 4, 5, 6, 7, 8, «아파트 E09 한국어 SDH» 큐 115, 120, 123, 150, 154, 158, 166, 860). 이는 넷플릭스의 한국어 스타일 가이드 I절의 규정에 어긋나는 부분이 있음을 시사한다. 반면, 오싹한 연애 E09의 경우 강제 자막은 화면 글자 '싱가포르 / 비즈니스 네트워킹 초청장'을 포함하고, SDH는 대사 '해외 출장 다녀오겠습니다'를 포함하였다(«오싹한 연애 E09 한국어 SDH» 큐 426). 또한, 강제 자막은 '네'와 '[한숨] 그래요?' 같은 대사를 생략한 반면, SDH에서는 이를 포함하였다(«오싹한 연애 E09 한국어 SDH» 큐 327, 328, 329, 333). 이러한 차이는 강제 자막이 특정 상황에서의 대사를 생략하는 경향이 있음을 나타내며, 넷플릭스 한국어 스타일 가이드에 부합하는 것으로 보인다.
