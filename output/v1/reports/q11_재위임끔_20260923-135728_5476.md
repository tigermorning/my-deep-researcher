# 넷플릭스 한국 드라마 강제 자막과 SDH 비교

> 질문: 넷플릭스 한국 드라마의 한국어 강제 자막(아파트 E09, 오싹한 연애 E09)은 어떤 대사·화면 글자에 붙었고, 같은 회차 한국어 SDH와 견주면 무엇이 빠지거나 더해졌는가? 넷플릭스 강제 자막 규정·한국어 가이드 I절과 맞는가?

본 보고서는 넷플릭스 한국 드라마 '아파트 E09'와 '오싹한 연애 E09'의 한국어 강제 자막과 한국어 SDH 간의 차이를 분석한다. 질문은 두 회차의 강제 자막이 어떤 대사와 화면 글자에 붙었는지, 그리고 SDH와 비교했을 때 어떤 내용이 빠지거나 더해졌는지를 다룬다. 이를 통해 넷플릭스의 자막 규정과 한국어 스타일 가이드 I절과의 일치 여부를 검토한다.

## 아파트 E09 강제 자막과 SDH 비교

넷플릭스의 한국 드라마 "아파트 E09"의 강제 자막과 한국어 SDH를 비교한 결과, 두 트랙 간에 여러 차이가 발견되었다. 예를 들어, 큐 860에서 SDH는 "[삑] / - [영어] 해독 시작"이라고 자막을 제공하는 반면, 강제 자막에서는 "해독 시작"만 포함되어 영어 부분이 빠졌다(«아파트 E09» 한국어 SDH 큐 1). 또한 큐 862에서는 SDH에 "아, 무슨 첩보 영화 찍냐?"라는 대사가 포함되어 있으나, 강제 자막에서는 이 대사가 누락되었다(«아파트 E09» 한국어 SDH 큐 1). 이와 유사하게, 큐 919와 큐 926에서도 SDH에는 대사가 포함되어 있지만, 강제 자막에서는 해당 대사가 빠져있다(«아파트 E09» 한국어 SDH 큐 1). 이러한 차이는 강제 자막이 특정 대사와 화면 글자를 생략하는 경향이 있음을 보여준다.  

넷플릭스의 한국어 스타일 가이드 I절에 따르면, 강제 자막은 플롯에 중요한 내용을 포함해야 하며, 대사와 화면 글자가 겹칠 경우 가장 중요한 메시지를 우선해야 한다(«넷플릭스 한국어 스타일 가이드 I. 번역 자막»). 그러나 실제로는 SDH에 포함된 많은 대사가 강제 자막에서 누락되어 있어, 이 규정에 어긋나는 것으로 보인다. 예를 들어, 큐 940과 큐 942에서도 SDH에는 대사가 포함되어 있으나, 강제 자막에서는 이 대사들이 빠져있다(«아파트 E09» 한국어 SDH 큐 1). 이러한 분석을 통해, 강제 자막이 SDH에 비해 플롯에 중요한 대사를 충분히 반영하지 못하고 있음을 확인할 수 있었다. 

결론적으로, "아파트 E09"의 강제 자막은 SDH에 비해 대사와 화면 글자의 누락이 많아, 넷플릭스의 자막 규정과 일치하지 않는 부분이 존재한다. 따라서 강제 자막의 개선이 필요하다고 판단된다.

## 오싹한 연애 E09 강제 자막과 SDH 비교

넷플릭스의 «오싹한 연애 E09»에서 강제 자막과 SDH를 비교한 결과, 두 트랙 간에 포함된 대사와 화면 글자에서 차이가 발견되었다. 예를 들어, 강제 자막에서는 "레이나 호텔 시에나 홀"이 포함되었고, 이는 SDH에서도 동일하게 나타났다(«오싹한 연애 E09» 한국어 강제 자막 큐 1, «오싹한 연애 E09» 한국어 SDH 큐 8). 그러나 SDH에는 [한숨]과 같은 비언어적 요소가 포함되었으나, 강제 자막에서는 이 부분이 누락되었다(«오싹한 연애 E09» 한국어 SDH 큐 9). 또한, 강제 자막은 "싱가포르 / 비즈니스 네트워킹 초청장"을 포함하고 있지만, SDH에서는 "해외 출장 다녀오겠습니다"라는 대사가 포함되어 있어, 강제 자막이 더 구체적인 정보를 제공하고 있다(«오싹한 연애 E09» 한국어 강제 자막 큐 2, «오싹한 연애 E09» 한국어 SDH 큐 426). 이와 같은 차이는 강제 자막이 특정한 플롯 관련 정보를 강조하는 반면, SDH는 더 많은 대화 내용을 포함하고 있다는 점에서 차별화된다. 또한, 강제 자막은 "건배"와 같은 간단한 대사를 포함하고 있지만, SDH에서는 이와 관련된 대사가 누락되었다(«오싹한 연애 E09» 한국어 강제 자막 큐 28, «오싹한 연애 E09» 한국어 SDH 큐 27). 이러한 차이는 넷플릭스 한국어 스타일 가이드의 규정에 따라, 플롯에 중요한 대사는 반드시 포함되어야 한다는 원칙에 부합한다(«넷플릭스 한국어 스타일 가이드 I. 번역 자막»). 그러나 강제 자막이 특정 대사를 생략한 경우도 있어, 모든 플롯 관련 대사가 포함되지 않은 점은 아쉬운 부분이다. 따라서, 강제 자막과 SDH 간의 차이는 주로 대화의 양과 플롯 관련 정보의 강조에 따라 달라진다.

## 맺음말

결론적으로, '아파트 E09'의 강제 자막은 SDH에 비해 대사와 화면 글자의 누락이 많아, 넷플릭스의 자막 규정과 일치하지 않는 부분이 존재한다. 반면, '오싹한 연애 E09'의 경우 강제 자막이 특정 플롯 관련 정보를 강조하는 경향이 있지만, 여전히 일부 대사가 생략된 점은 아쉬운 부분이다. 따라서 두 작품 모두 강제 자막의 개선이 필요하다고 판단된다. 이러한 분석은 넷플릭스 한국어 스타일 가이드 I절의 규정에 따라, 플롯에 중요한 대사는 반드시 포함되어야 한다는 원칙에 부합해야 함을 시사한다.
