# 넷플릭스 한국 드라마의 강제 자막과 SDH 비교

> 질문: 넷플릭스 한국 드라마의 한국어 강제 자막(아파트 E09, 오싹한 연애 E09)은 어떤 대사·화면 글자에 붙었고, 같은 회차 한국어 SDH와 견주면 무엇이 빠지거나 더해졌는가? 넷플릭스 강제 자막 규정·한국어 가이드 I절과 맞는가?

본 보고서는 넷플릭스 한국 드라마의 강제 자막과 한국어 SDH 간의 차이를 분석한다. 아파트 E09와 오싹한 연애 E09의 각 회차에서 어떤 대사와 화면 글자가 포함되었는지 살펴보고, 두 자막 간의 차이를 정리하였다. 이를 통해 넷플릭스의 강제 자막 규정과 한국어 가이드 I절과의 일치 여부를 검토한다.

## 아파트 E09 강제 자막과 SDH 비교

아파트 E09의 강제 자막과 SDH를 비교한 결과, 두 트랙 간에 여러 차이가 발견되었다. 첫째, 강제 자막에는 "충원/전화"라는 대사가 포함되어 있으나, SDH에는 해당 대사가 없다(«아파트 E09» 한국어 SDH 큐 3). 둘째, 강제 자막에는 "해독 시작"이라는 대사가 포함되어 있으나, SDH에는 해당 대사가 없다(«아파트 E09» 한국어 SDH 큐 860). 셋째, 강제 자막에는 "[안내 음성] 경비가 해제되었습니다"라는 내용이 포함되어 있으나, SDH에는 해당 안내 음성이 없다(«아파트 E09» 한국어 SDH 큐 878). 넷째, 강제 자막에는 "[경남의 중얼거림] 잠, 잠시만요, 형님"이라는 효과음이 포함되어 있으나, SDH에는 해당 효과음이 없다(«아파트 E09» 한국어 SDH 큐 1312). 이러한 차이는 넷플릭스의 강제 자막 규정에 따라, 강제 자막은 대사와 화면 글자를 명확히 전달하기 위해 필요한 내용을 포함해야 한다는 점에서 일치한다(«넷플릭스 FAQ: 강제 자막이란»). 그러나 SDH는 대사와 효과음을 모두 포함해야 하므로, 강제 자막에 포함된 내용이 SDH에서 누락된 것은 규정에 어긋난다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 따라서 강제 자막과 SDH 간의 차이는 명확히 드러나며, 이는 시청자에게 필요한 정보를 제공하기 위한 강제 자막의 목적과 일치한다(«넷플릭스 강제 자막 이해하기»).

## 오싹한 연애 E09 강제 자막과 SDH 비교

오싹한 연애 E09의 강제 자막과 SDH를 비교한 결과, 두 트랙 간에 포함된 대사와 화면 글자에서 차이가 나타났다. 예를 들어, 강제 자막에서는 00:02:08에 "레이나 호텔 시에나 홀"이 포함되어 있으며, 이는 SDH에서도 동일하게 나타난다(«오싹한 연애 E09» 한국어 강제 자막 큐 1, «오싹한 연애 E09» 한국어 SDH 큐 8). 그러나 00:02:15의 [한숨]과 같은 효과음은 강제 자막에는 포함되지 않고 SDH에만 나타난다(«오싹한 연애 E09» 한국어 SDH 큐 9). 이와 유사하게, 00:03:00의 - [묘순] 제가, 저…와 같은 대사도 강제 자막에는 없고 SDH에만 존재한다(«오싹한 연애 E09» 한국어 SDH 큐 27). 또한, 00:04:49의 - [묘순] 야 와 이라노 / - [필동, 형민] 왜 저래?와 같은 대사도 강제 자막에는 포함되지 않는다(«오싹한 연애 E09» 한국어 SDH 큐 56). 00:24:15의 [여리] 해외 출장 다녀오겠습니다는 강제 자막에서 "싱가포르 / 비즈니스 네트워킹 초청장"으로 변환되어 포함되지만, SDH에는 해당 내용이 없다(«오싹한 연애 E09» 한국어 강제 자막 큐 2, «오싹한 연애 E09» 한국어 SDH 큐 426). 이처럼 강제 자막은 특정 대사와 화면 글자를 포함하고 있지만, SDH에서 제공하는 효과음 및 추가 대사들은 누락되어 있다. 이는 넷플릭스의 강제 자막 규정에 따라, 강제 자막은 대사와 화면 글자를 명확히 전달하기 위한 것이며, SDH와는 다르게 특정 대사나 효과음을 생략할 수 있음을 보여준다(«넷플릭스 FAQ: 강제 자막이란»). 따라서 강제 자막은 SDH와 비교할 때 일부 대사가 빠지거나 추가된 경우가 있으며, 이는 넷플릭스의 강제 자막 규정과 일치한다. 전반적으로, 강제 자막은 특정 상황에서 필요한 정보를 제공하는 데 중점을 두고 있으며, SDH는 보다 포괄적인 내용을 포함하고 있다.

## 맺음말

아파트 E09의 강제 자막은 SDH에 비해 여러 대사와 안내 음성을 포함하고 있으며, 이는 넷플릭스의 강제 자막 규정에 부합한다. 반면, 오싹한 연애 E09의 경우 강제 자막은 특정 대사와 효과음을 생략하고 있어 SDH와의 차이가 명확하다. 아파트 E09에서는 '충원/전화', '해독 시작', '[안내 음성] 경비가 해제되었습니다', '[경남의 중얼거림] 잠, 잠시만요, 형님'이 강제 자막에 포함되었으나 SDH에는 없다. 오싹한 연애 E09에서는 '레이나 호텔 시에나 홀'은 두 자막 모두에 포함되지만, '[한숨]', '[묘순] 제가, 저…', '[묘순] 야 와 이라노 / - [필동, 형민] 왜 저래?'는 SDH에만 존재한다. 이러한 차이는 강제 자막이 특정 상황에서 필요한 정보를 제공하는 데 중점을 두고 있음을 보여준다.
