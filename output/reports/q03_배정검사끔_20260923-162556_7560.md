# 넷플릭스 한국어 SDH 트랙의 화자·효과음·음악 표기 검토

> 질문: 넷플릭스 한국어 SDH 트랙 셋(대체 등산을 왜 하는 건데? E01, 이서진의 달라달라 E01, 도라이버 시즌2 E15)의 화자·효과음·음악 표기는 넷플릭스 한국어 스타일 가이드 SDH 절(II)과 맞는가?

본 보고서는 넷플릭스 한국어 SDH 트랙의 화자, 효과음, 음악 표기가 넷플릭스 한국어 스타일 가이드 SDH 절과 일치하는지를 검토한 결과를 제시한다. 세 개의 절, 즉 대체 등산을 왜 하는 건데? E01, 이서진의 달라달라 E01, 도라이버 시즌2 E15의 원고를 바탕으로 각 트랙의 표기 방식이 가이드와 어떻게 다른지를 분석하였다.

## 대체 등산을 왜 하는 건데? E01 한국어 SDH

«대체 등산을 왜 하는 건데? E01» 한국어 SDH의 화자, 효과음, 음악 표기가 «넷플릭스 한국어 스타일 가이드 II. SDH»와 일치하는지 검토한 결과, 몇 가지 규정에 어긋나는 부분이 발견되었다. 첫째, 화자 표기와 관련하여, «대체 등산을 왜 하는 건데? E01» 한국어 SDH에서는 하이픈(-)으로 시작하는 줄이 124줄 존재하는데, 이는 화자와 효과음이 다른 출처에서 발생할 때 하이픈을 사용해야 한다는 규정(II.5 Dual Speaker/Multiple Events)과 일치하지 않는다. 둘째, 효과음 표기와 관련하여, «대체 등산을 왜 하는 건데? E01» 한국어 SDH의 큐 144에서 효과음이 하이픈으로 시작하고 있으며, 이는 화자와 효과음이 동일한 출처에서 발생할 때 하이픈을 사용하지 않아야 한다는 규정(II.5 Dual Speaker/Multiple Events)과 어긋난다. 셋째, 효과음 표기에서 «넷플릭스 한국어 스타일 가이드 II. SDH»의 규정(II.9 Sound Effects)에 따르면, 효과음은 대괄호 [ ]로 감싸야 하는데, «대체 등산을 왜 하는 건데? E01» 한국어 SDH에서는 효과음이 대괄호로 감싸지지 않고 있다. 마지막으로, 음악 표기와 관련하여, «대체 등산을 왜 하는 건데? E01» 한국어 SDH에서는 음악에 대한 언급이 없으며, 이는 규정(II.7 Songs and Music)에 따라 음악이 플롯에 중요한 경우 자막으로 제공해야 한다는 점에서 부족하다. 따라서, «대체 등산을 왜 하는 건데? E01» 한국어 SDH의 화자, 효과음, 음악 표기는 «넷플릭스 한국어 스타일 가이드 II. SDH»와 일치하지 않는다. 이 절은 지시에 답하기에 충분하지 않으며, 효과음과 음악 표기 관련 구간을 더 확인해야 한다.

## 이서진의 달라달라 E01 한국어 SDH

이서진의 달라달라 E01 한국어 SDH 트랙의 화자, 효과음, 음악 표기는 넷플릭스 한국어 스타일 가이드 SDH 절과 일부 일치하지 않는다. 첫째, 화자 표기와 관련하여, 이서진의 달라달라 E01에서는 하이픈(-)으로 시작하는 줄이 178줄로 나타나며, 이는 화자와 효과음을 구분하는 데 사용되었다(«이서진의 달라달라 E01» 한국어 SDH 큐 1). 그러나 넷플릭스 스타일 가이드에서는 화자와 효과음이 다른 출처에서 발생할 경우 하이픈을 사용하라고 명시하고 있다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 둘째, 효과음 표기에서, 이서진의 달라달라 E01에서는 효과음이 대괄호 [ ]로 표기되었고, 이는 가이드와 일치한다(«이서진의 달라달라 E01» 한국어 SDH 큐 14). 그러나 효과음의 설명이 부족한 경우가 있어, 효과음이 시각적으로 식별되지 않을 때는 설명을 추가해야 한다는 규정이 있다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 셋째, 음악 표기와 관련하여, 이서진의 달라달라 E01에서는 음악이 [ ]로 표기되었고, 이는 가이드의 지침에 부합한다(«이서진의 달라달라 E01» 한국어 SDH 큐 75). 그러나 음악의 제목을 인용할 때는 따옴표를 사용해야 한다는 규정이 있다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 마지막으로, 줄 길이에 대한 규정도 확인해야 한다. 이서진의 달라달라 E01에서는 가장 긴 줄이 21자로, 16자 이상인 줄이 81줄로 나타났다(«이서진의 달라달라 E01» 한국어 SDH). 이는 16자 제한을 초과하는 경우가 있어, 가이드와 일치하지 않는다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 따라서 이서진의 달라달라 E01 한국어 SDH 트랙은 일부 규정에 맞지 않으며, 추가적인 검토가 필요하다.

## 도라이버 시즌2 E15 한국어 SDH

도라이버 시즌2 E15 한국어 SDH 트랙의 화자, 효과음, 음악 표기는 넷플릭스 한국어 스타일 가이드 SDH 절과 일부 일치하지 않는다. 첫째, 화자 ID 사용에 대한 규정이 명확히 지켜지지 않았다. 가이드에 따르면, 화자가 시각적으로 식별되지 않을 경우 화자 ID를 사용해야 하며, 이미 식별된 화자의 경우 추가적인 화자 ID는 필요하지 않다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 그러나 도라이버 시즌2 E15에서는 하이픈(-)으로 시작하는 줄이 624줄로, 이는 화자 ID가 필요할 때 사용되지 않은 경우가 많음을 나타낸다(«도라이버 시즌2 E15» 한국어 SDH 큐 1). 예를 들어, 큐 2에서 화자가 시각적으로 식별되지 않음에도 불구하고 하이픈으로 시작하여 화자 ID가 누락되었다(«도라이버 시즌2 E15» 한국어 SDH 큐 2). 둘째, 효과음 표기에서 가이드에 명시된 대로 효과음은 대괄호 [ ]로 감싸야 하며, 효과음이 시각적으로 식별되지 않을 경우 상세히 설명해야 한다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 도라이버 시즌2 E15에서는 효과음이 대괄호로 잘 표기되었으나, 설명이 부족한 경우가 있다. 예를 들어, 큐 5의 경우 - 아유 / - [제작진의 웃음]으로 표기되었으나, 효과음의 성격에 대한 설명이 부족하다(«도라이버 시즌2 E15» 한국어 SDH 큐 5). 셋째, 음악 표기 또한 가이드에 따라 적절히 이루어져야 하며, 음악의 성격을 설명하는 것이 바람직하다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 도라이버 시즌2 E15에서는 음악이 [ ]로 잘 표기되었으나, 음악의 성격을 설명하는 경우가 적어 아쉬움이 남는다(«도라이버 시즌2 E15» 한국어 SDH 큐 1). 따라서, 도라이버 시즌2 E15의 SDH 트랙은 넷플릭스 한국어 스타일 가이드 SDH 절과 완전히 일치하지 않으며, 화자 ID 사용과 효과음 및 음악 설명에서 개선이 필요하다.

## 맺음말

대체 등산을 왜 하는 건데? E01의 화자, 효과음, 음악 표기는 넷플릭스 한국어 스타일 가이드 II. SDH와 일치하지 않으며, 하이픈 사용, 효과음 대괄호 미사용, 음악 언급 부족 등의 문제가 발견되었다. 이서진의 달라달라 E01 또한 화자 표기에서 하이픈 사용, 효과음 설명 부족, 음악 제목 인용 시 따옴표 미사용 등으로 일부 규정에 맞지 않았다. 도라이버 시즌2 E15는 화자 ID 사용 미비, 효과음 설명 부족, 음악 성격 설명 부족 등의 문제로 가이드와 완전히 일치하지 않는다. 따라서 세 개의 SDH 트랙 모두 추가적인 검토와 개선이 필요하다.
