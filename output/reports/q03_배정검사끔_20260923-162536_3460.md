# 넷플릭스 한국어 SDH 트랙의 화자·효과음·음악 표기 검토

> 질문: 넷플릭스 한국어 SDH 트랙 셋(대체 등산을 왜 하는 건데? E01, 이서진의 달라달라 E01, 도라이버 시즌2 E15)의 화자·효과음·음악 표기는 넷플릭스 한국어 스타일 가이드 SDH 절(II)과 맞는가?

본 보고서는 넷플릭스 한국어 SDH 트랙의 화자, 효과음, 음악 표기가 넷플릭스 한국어 스타일 가이드 SDH 절과 일치하는지를 검토한 것이다. 세 개의 절, 즉 대체 등산을 왜 하는 건데? E01, 이서진의 달라달라 E01, 도라이버 시즌2 E15의 원고를 바탕으로 각 절의 표기 방식의 차이점을 분석하였다.

## 대체 등산을 왜 하는 건데? E01 한국어 SDH

«대체 등산을 왜 하는 건데? E01» 한국어 SDH의 화자, 효과음, 음악 표기가 «넷플릭스 한국어 스타일 가이드 II. SDH»와 비교했을 때 몇 가지 차이점이 발견되었다. 첫째, 화자 표기에서 «대체 등산을 왜 하는 건데? E01» 한국어 SDH는 하이픈(-)으로 시작하는 줄이 124줄로 나타났는데, 이는 화자와 효과음을 구분하는 규정에 어긋난다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 가이드에 따르면, 하이픈은 서로 다른 출처에서 발생하는 화자와 효과음을 구분할 때 사용해야 하며, 화자 자신이 효과음을 내는 경우에는 하이픈을 사용하지 않아야 한다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 둘째, 효과음 표기에서 «대체 등산을 왜 하는 건데? E01» 한국어 SDH는 효과음이 25줄로 나타났고, 이 중 일부는 하이픈으로 시작하는 줄로 표기되었다. 이는 효과음 표기 규정에 위배된다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 셋째, 음악 표기와 관련하여 «대체 등산을 왜 하는 건데? E01» 한국어 SDH에서는 음악에 대한 언급이 없었으며, 이는 가이드에서 음악이 플롯과 관련이 있을 경우 자막으로 제공해야 한다는 규정에 어긋난다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 마지막으로, 화자 ID 표기에서 «대체 등산을 왜 하는 건데? E01» 한국어 SDH는 화자 ID를 대괄호로 표기하지 않고, 일반 텍스트로 표기한 경우가 많았다. 이는 가이드에서 화자 ID는 반드시 대괄호로 표기해야 한다고 명시하고 있는 점과 일치하지 않는다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 따라서 «대체 등산을 왜 하는 건데? E01» 한국어 SDH의 화자, 효과음, 음악 표기는 «넷플릭스 한국어 스타일 가이드 II. SDH»와 일치하지 않는다.

## 이서진의 달라달라 E01 한국어 SDH

이서진의 달라달라 E01 한국어 SDH 트랙의 화자, 효과음, 음악 표기는 넷플릭스 한국어 스타일 가이드 SDH 절과 일부 일치하지 않는다. 첫째, 효과음 표기에서 하이픈(-) 사용이 규정에 맞지 않는 경우가 있다. 예를 들어, 큐 52에서는 '[딸랑딸랑 - 효과음]'으로 표기되었는데, 이는 하이픈을 사용하여 화자와 효과음을 구분하는 방식으로, 스타일 가이드의 지침에 어긋난다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 둘째, 큐 75에서 '[긴장되는 효과음] / - [의미심장한 음악]'처럼 두 개의 효과음과 음악이 함께 표기된 경우, 하이픈 사용이 불필요하다. 이는 효과음이 화자와 다른 출처에서 발생하지 않기 때문이다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 셋째, 큐 90에서 '- [영석] 아이, 씨'와 같은 표기는 화자 표기와 대사를 혼합하여 사용하고 있어, 이는 규정에 맞지 않다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 넷째, 큐 14와 큐 183에서 '[익살스러운 효과음]'과 '[딸랑딸랑 - 효과음]'처럼 효과음이 대괄호로 표기되었으나, 하이픈 사용이 불필요한 경우가 있다(«작업자 자료: SDH 효과음 예시»). 마지막으로, 큐 321에서 '[제작진들의 웃음]'과 같은 표기는 효과음으로 적절하게 표기되었으나, 이와 같은 표기가 전체적으로 일관되게 적용되지 않았다(«이서진의 달라달라 E01» 한국어 SDH). 따라서, 이서진의 달라달라 E01 한국어 SDH 트랙은 넷플릭스 한국어 스타일 가이드 SDH 절과 완전히 일치하지 않으며, 하이픈 사용과 서술형 표기에 대한 구간을 추가로 확인해야 할 필요가 있다.

## 도라이버 시즌2 E15 한국어 SDH

넷플릭스 한국어 SDH 트랙의 화자, 효과음, 음악 표기가 넷플릭스 한국어 스타일 가이드 SDH 절과 일치하는지 검토하였다. 첫째, 화자 표기와 관련하여, 하이픈(-)으로 시작하는 줄이 624줄로 확인되었으며, 이는 화자와 효과음이 다른 경우에 대한 규정을 준수하고 있다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 둘째, 효과음 표기에서, 대괄호 [ ]를 사용하여 효과음을 표기한 경우가 229줄로 확인되었고, 이는 효과음이 시각적으로 식별되지 않을 때 대괄호를 사용하라는 규정에 부합한다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 셋째, 음악 표기 또한 대괄호 [ ]를 사용하여 113개가 확인되었으며, 이는 음악을 효과음과 동일하게 처리하라는 지침을 따르고 있다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 그러나, 화자 ID를 소괄호로 표기해야 하는 규정이 있음에도 불구하고, 화자 ID가 소괄호로 표기된 경우는 없었다(«넷플릭스 한국어 스타일 가이드 II. SDH»). 이로 인해 화자 식별이 명확하지 않은 경우에 대한 규정이 어긋나고 있다. 마지막으로, 줄 길이에 대한 규정은 준수되었으며, 가장 긴 줄이 22자로 확인되었다(«도라이버 시즌2 E15» 한국어 SDH). 따라서, 도라이버 시즌2 E15 한국어 SDH 트랙은 전반적으로 넷플릭스 한국어 스타일 가이드 SDH 절과 일치하나, 화자 ID 표기에서의 일관성이 부족하다. 이 절이 지시에 답하기에 충분하다고 판단된다.
